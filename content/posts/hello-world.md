本站的第一篇文章，就让这个博客主题的作者来帮本人说句开场白吧：

#### 如果可以的话，*AIOVTUE-雪* 希望帮你来说这句话，**你好，世界！**

说起 `Hello World`，本人编写的第一个程序并不是`print Hello World`，也不是很多 OIer 熟知的信竞网站`洛谷`上面的第一道题`A + B Problem`，而是带我入门 C++ 编程的老师出的一道题：输出三个正整数中最大的数。于是我写出了人生中第一个程序：

~~~cpp
#include<iostream>
using namespace std;
int main(){
    int a,b,c;
    cin>>a>>b>>c;
    if (a>b>c)
      cout<<a;
    else if (b>a>c)
      cout<<b;
    else if (b>c>a)
      cout<<b;
    else
      cout<<c;
    return 0;
}
~~~

显而易见，答案是错的 ~~（经高人提醒这段代码居然是可以正常编译的，原因是发生了类型隐式转换，C无敌了）~~。老师告诉我说代码里没有连续小于的语法，随后老师手把手一个字符一个字符地带本人写出了最终版本：

~~~cpp
#include<iostream>
using namespace std;
int main(){
    int a,b,c;
    cin>>a>>b>>c;
    if(a>b){
        if(a>c) cout<<a;
        else cout<<c;
    }
    else{
        if(b>c) cout<<b;
        else cout<<c;
    }
    return 0;
}
~~~

随后我就发出了稚嫩的疑问：“那可以连等吗？”

被泼了冷水的本人短时间内减少了对编程的向往。

但现在想想，其实当时的思路也没有错。按照正确的语法和本人现在的码风再`重构`一遍：

~~~cpp
#include <iostream>
using namespace std;
int main(){
    int num1, num2, num3;
    cin >> num1 >> num2 >> num3;
    if (num1 > num2 && num1 > num3){
        cout << num1 << '\n';
    }
    else if (num2 > num1 && num2 > num3){
        cout << num2 << '\n';
    }
    else {
        cout << num3 << '\n';
    }
}
~~~

其实也挺好，不是吗？

后来听说了 `Hello World` 的故事，也没太在意。最有感触的一次是在大一第一节`程序设计`课上，那时的我还在为另一个梦想努力，希望有朝一日能在 ACM 的赛场上作为夺得金牌的队伍被滚榜主持人念出我们的队名。正好那节课让我们用 C 写一个`print Hello World`作为我们大学里的第一个程序，如此有仪式感的事情怎能不令本人热血沸腾，于是对此留下了深刻的印象。

虽然对上`程序设计`的课不感兴趣，但对编程的学习却丝毫没有懈怠。上大学一个月本人便初步通过阅读`Professional-C++`这本书将码风基本更新为`Modern C++`，以至于有些钻牛角尖：学 C 时尽量尝试用 `struct` 实现面向对象编程；学 C++ 时坚持用 `unique_ptr` 和 `shared_ptr`。不用 AI，不对外展示，只是一味地沉浸在自己的代码艺术里。备战 ACM 的时候也一直坚持古法学习，看网课、打周赛、读题解、做复盘。

一切都在接触 Agent 后结束了，学习的算法、数据结构够不到 GPT 大人的鞋底，就连码风也因为统一更换为`Modern C++`导致被 AI 完全替代，只能在代码生成完后将) {之间的空格删去作为本人留下的唯一人工痕迹。

随之而来的便是迷茫，那时的感觉和这篇博客[迷茫随写](https://ri-nai.github.io/astro-blog/blog/2025/09/18/%E8%BF%B7%E8%8C%AB%E9%9A%8F%E5%86%99/)一样，对什么事情都提不起兴趣，整日堕落于彩虹六号和卫戍协议中。`我失去的是对赛车的热爱`——出自电影《F1》，我发现我失去的是对代码的热爱。

不过转机出现在大二下的期末月，`操作系统原理实验`这门课成功让我找回了 Sonny Hayes 那种`飞翔的感觉`，坐在电脑前开着单曲循环一晚上，Codex 跑代码，我写实验报告，遇到问题立刻解决，绝不拖到下一天，也算是和 Agent 和解了。那时手表统计的连续 7 天的平均入睡时间是03：56，甚至有一天想 12 点睡觉，结果 5 点被舍友打游戏吵醒后睡不着，于是翻身下床写实验报告到 7 点再回去继续睡。

好景不长，暑假开始了。意志刚刚开始坚定便遭遇了毁灭性打击，放假前做好的学习计划（做导师给的项目、学完[动手学强化学习](https://hrl.boyuai.com/)、搭一个个人博客）也还是比不过出门和朋友玩有意思。逐渐摆烂时突发奇想翻了下收藏夹里的一个偶然间发现的博客，里面就有这篇文章[迷茫随写](https://ri-nai.github.io/astro-blog/blog/2025/09/18/%E8%BF%B7%E8%8C%AB%E9%9A%8F%E5%86%99/)

~~~
我一直想学一些更常规的开发技术，但懒了。我不知道未来的开发会是什么样，但在学校里，我似乎一直活在AI辅助编程的舒适区里，没能真正独立地去做开发。

暑假也懒了，好懒。

或许这才是大学的常态吧。

周围的人都好厉害，有那种精通 CV 科研的，有那种暑假已经开始实习的，有那种一直在开发各种有意义的小玩意的，有那种对软件工程上的各种知识都了如指掌的。
~~~

感触颇深，于是火速调整状态，搭建了这个小站。

大二上，感觉一直在装模作样地学习。一边拿ACM作幌子，说自己很忙，一边又没能在队里发挥什么作用，像个混子，心里有点愧疚。那学期学业压力确实非常重，我几乎没怎么玩游戏，但回想起来，花在正事上的时间还是太少了。
